# Archived specs — screens that no longer exist in Figma

Everything in this folder describes screens **deleted on 2026-09-19**, when `AUTH`,
`ONBOARDING` and `REGISTRATION · CONNECTED UX FLOW` (32 screens) were replaced by the
single `START` flow (5 screens). See RULES.md section Y.

**Do not build from these files.** They are kept for two reasons: the copy took work to get
right, and some of the patterns are worth rebuilding when the paths that need them are
designed.

| File | What it holds |
|---|---|
| `registration-flows.md` | All 32 screens — full structure for AUTH and ONBOARDING, copy for REGISTRATION |
| `onboarding-register-method.md` | The MyGov vs documents choice, with a written reading of the visual hierarchy |
| `onboarding-mygov-handoff.md` · `onboarding-mygov-failure.md` | The MyGov round trip and its failure case |
| `onboarding-id-scan.md` · `onboarding-licence-scan.md` | The document viewfinder pattern |

The five `onboarding-*.md` files were written by another agent working from the live Figma
nodes, and carry prose descriptions alongside the node trees. They are the better reference
if the document-capture path is rebuilt — see GAPS.md, "Re-opened by that change".

The live specs are one directory up, one file per lane.
